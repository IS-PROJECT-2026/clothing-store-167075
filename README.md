# KITU. Clothing Store

A small, modern e-commerce landing page and storefront for a Nairobi-based fashion brand. The site includes a product catalog, category filters, search, add-to-cart interactions, and supporting About and Contact pages.

## Features

- Responsive storefront layout with hero section and navigation
- Product grid rendered from structured JavaScript data
- Search bar for filtering products by name or category
- Category filter chips for navigation across product types
- Add-to-cart counter and toast confirmation feedback
- About and Contact pages styled to match the main storefront
- Mobile-friendly hamburger navigation

## Project structure

- [index.html](index.html) — main shop/home page
- [about.html](about.html) — brand story and studio information
- [contact.html](contact.html) — contact details and enquiry info
- [products.js](products.js) — product catalog data
- [script.js](script.js) — product rendering and interaction logic
- [style .css](style%20.css) — site styling and responsive behaviours

## Run locally

From the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
